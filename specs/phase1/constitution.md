# Project Constitution

## 1. Project Name
Todo App Phase 1

## 2. Mission
To create a simple, fast, and reliable command-line interface (CLI) application for managing daily tasks.

## 3. Guiding Principles
- **Simplicity:** The application should be easy to use with a minimal set of commands.
- **CLI-First:** The primary interface will be the command line.
- **Stateless:** The application will not persist data between sessions in Phase 1. Data is stored in memory.
- **Extensibility:** The code should be written in a way that allows for future expansion (e.g., saving tasks to a file, adding more commands).

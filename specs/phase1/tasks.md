# Phase 1: Task Checklist

## Core Features

- [x] **Add Task**: User can add a new task.
- [x] **List Tasks**: User can see all existing tasks.
- [x] **Update Task**: User can modify the description of an existing task.
- [x] **Delete Task**: User can remove a task from the list.
- [x] **Complete Task**: User can mark a task as completed.

- [x] **Main Loop**: The application runs in a continuous loop.
- [x] **Command Input**: The user can enter commands.
- [x] **Exit**: The user can exit the application gracefully.

## Code Quality & UX

- [x] **Input Validation**: The application handles invalid task IDs.
- [x] **Visual Separators**: Use separators to make the output more readable.
